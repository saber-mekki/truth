# 🕊️ The Truth – Gaza Awareness App

**The Truth** is a web application built to visually present the humanitarian impact of the ongoing genocide in Gaza. Through a collection of photos and real-time statistics, the app aims to raise awareness and preserve the memory of the victims.

---

## 📸 Features

- 🔢 **Live Statistics**  
  Fetches real-time casualty and humanitarian data from [Tech For Palestine's Summary API](https://data.techforpalestine.org/api/v2/summary.json), including:
  - Total deaths
  - Children and women killed
  - Wounded and missing persons
  - Journalists, medical staff, and civil defense martyrs
  - Number of documented massacres
  - Last updated date

- 🖼️ **Photo Gallery**  
  A powerful image gallery with zoom functionality to document and humanize the tragedy.

- 🔊 **Background Audio**  
  Auto-plays a low-volume background audio file to create an immersive, respectful atmosphere.

- 📱 **Responsive Design**  
  Optimized for desktop and mobile viewing.

---

## 🚀 Technologies Used

- **Next.js**
- **React**

## 📡 Data Source

> All statistics are fetched live from:  
> 📊 [`https://data.techforpalestine.org/api/v2/summary.json`](https://data.techforpalestine.org/api/v2/summary.json)  
> A free and open humanitarian API provided by [Tech for Palestine](https://data.techforpalestine.org).
